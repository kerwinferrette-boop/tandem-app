## Things that bit this session

- **A command chain with `cd` that fails midway keeps running in the old directory.** Use absolute
  `cd` at the start of every command; confirm `git branch --show-current` before merging.
- **"The output differs" is not "it works"** (SC-59). Measure the quantity the label promises.
- **A check that cannot fail is not a check.** Two assertions written this session passed under
  every mutation and had to be rewritten or declared unproven.
- **Three branches each raising the check floor to the same number** conflict on merge. Recompute
  the floor from the merged `verify.mjs` as `check-floor-smoke.mjs` parses it — a `name:` grep
  undercounts by one.
- **`program-snapshot.json` is regenerated on a merge result, never picked from a side.**
- **Remove the `node_modules` symlink from a temp worktree before committing.**
