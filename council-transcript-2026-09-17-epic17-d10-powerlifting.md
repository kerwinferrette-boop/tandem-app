# LLM Council — EPIC-17 / D10 powerlifting rep-band fork

**Date:** 2026-09-17
**Convened by:** scheduled loop session, attended (Kerwin live)
**Question asked:** Should an ancillary/secondary training goal (EPIC-17, e.g. a powerlifting meet) be permitted to override the PRIMARY goal's rep-range band — a D10/D2 doctrine question?

## Framed question

DOCTRINE.md invariant D10 (ACTIVE) requires rep schemes to honor each goal's own band — Build Muscle is fixed at 6-15 reps (hypertrophy), and 1-5 (strength) is explicitly forbidden for that goal. EPIC-17's Expected Behavior asks that a user whose PRIMARY goal is Build Muscle but who selects "powerlifting_meet" as an ancillary/secondary goal get "SBD focus with 1-3RM periodization" — directly violating D10, and more extreme than the app's existing rep_floor:3. There is a related D2 question ("only the canonical goals exist") — a modifier that restructures the program's rep scheme this drastically is functionally acting as a second goal, not a cosmetic add-on.

Options weighed: (a) permit an ancillary goal to override the primary's rep band under narrow conditions; (b) reject — ancillary goals never touch the primary goal's rep-band contract; (c) hybrid — only inside a labeled taper/peak block.

## Advisor responses

Section 5's strength band is "1-5 reps, 85-100% 1RM," not 1-3. Nowhere in this document does "1-3RM" or "SBD" appear. EPIC-17's "1-3RM periodization" isn't a citation, it's a flourish someone typed into Notion because it sounds authentically powerlifting. If this ships, it ships as 3-5, full stop — 1-3 has zero support. The bigger problem nobody's naming: this isn't a rep-band question, it's a D2 end-run. An "ancillary goal" that overwrites the primary's rep contract isn't ancillary — it's a second goal wearing a disguise to skip D2's actual legality bar. There's also a live safety gap being skipped: D21 gates RM-based prescriptions behind an earned 1RM (D11/D12) precisely because unearned max-effort work is dangerous. Does EPIC-17's SBD periodization check for an earned max before prescribing near-max singles to a hypertrophy-trained user? If that question hasn't been asked, this isn't ready to discuss rep numbers at all. If any version ships, it's (c) narrowly — dedicated, labeled peak block, capped at 3-5, gated on an earned 1RM, and D2 has to rule first on whether this is actually a goal.

### The First Principles Thinker

It's asking to become the primary goal, while being billed to the system as a lightweight add-on so it skips the cost of actually being one: its own MEV/volume table, its own phase structure, its own doctrine row, its own citation. That's not an override question, it's a smuggled sixth goal, and D2's "only the canonical goals exist" is the correct instinct catching it. §6 contains exactly one strength-phase rep prescription — "Mesocycle 2 (Strength Phase): 4 weeks at 3-5 reps, RPE 8-9" — which is precisely what the existing rep_floor:3 already licenses. There is no 1-3RM anywhere in this source. The real question isn't "override, how much." It's: does a powerlifting-meet training block deserve to exist as a real, doctrine-covered goal-state with its own citation-backed band, sequenced via block transition — or does it not exist at all yet.

### The Expansionist

Go big on (c), not small: build the taper/peak block as a genuine third architectural primitive (not a goal, not a modifier — a mesocycle TYPE), sourced at 3-5 reps per §6, with its own D-invariant governing entry/exit conditions.

## Chairman synthesis

### Where the Council Agrees
"1-3RM periodization" is dead — the string appears nowhere in the 18-page document, zero citation, ships in no option. Option (a) broadly is off the table. The real mechanism question is D2, not D10 — a rep-band contract IS how a goal is operationally defined; an "ancillary goal" rewriting the primary's rep band is a sixth canonical goal wearing a costume. D16 already built the override door (a template_id-scoped, cited rep_floor override key, already live at floor 3) — no new architecture needed.

### Where the Council Clashes — RESOLVED by the chairman re-opening the source
The advisors split 4-1 on whether §6 is a valid citation for a 3-5 rep strength-phase number. The chairman re-opened the PDF directly: **Advisor E is correct.** The report's Executive Summary (p.4) and Conclusion (p.16) both name "Skill Level Progressions" (confirmed via the Table of Contents as Section 6's actual title) among topics requiring "specialized strength sport and biomechanics literature beyond the current research scope." §6's "3-5 reps, RPE 8-9" line carries footnotes resolving to a CPT-certification textbook chapter and a NASM marketing blog post — real footnotes, wrong tier, disclaimed section.

But this doesn't leave the council with nothing: **Section 3** ("Training Variables by Goal") is NOT on the out-of-scope list, and states plainly: "Strength (1-5 rep range, 85-100% 1RM): Compound lifts at 85-100% 1RM [ACSM position stand, ref 7]. Target RIR 1-2 for strength protocols [ref 48]. Rest 3-5 min for CNS recovery." This is exactly the number D10 already uses internally ("never 1-5 strength"). The doctrine has quietly had the correct citation the whole time — EPIC-17 drifted into the wrong, disclaimed section chasing a number that sounded more specific.

### Blind Spots the Council Caught
All three peer reviews correctly flagged that nobody re-opened the source before recommending a fallback number. C's blind spot (enthusiasm outpacing citation verification) is now confirmed material. One thing no advisor or reviewer raised: D10's text already contains the correct number (1-5) — the doctrine wasn't wrong, EPIC-17's proposal wandered off it.

### The Recommendation
(c), narrowly, and only under D2's authority — not (a), not a full independent "peaking" primitive yet.
- Reject "1-3RM" outright — fabrication, not a gap, delete without a research pass.
- The valid strength-phase number is **1-5 reps, 85-100% 1RM, RIR 1-2, 3-5min rest — cited to Section 3, not Section 6.** rep_floor:3 already sits inside this validated band.
- Do not let an "ancillary goal" touch D10's rep-band contract. Ships as a labeled, template_id-scoped peak/taper block flag reusing D16's existing rep_floor/science_overrides machinery — not a sixth goal.
- Gate on an earned 1RM (D11/D12/D21's existing chain) before generating any set below rep_floor:3.
- The D2 question — is "peak block before a real meet" a legitimate goal-adjacent primitive, or a naming collision dodging D2's legality bar — is a genuine judgment call the science doesn't decide. Route to a NEW llm-council session before drafting a doctrine row.
