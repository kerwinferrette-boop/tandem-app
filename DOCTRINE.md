enforces it in `npm run verify`. All three stay in sync — `tandem-tpm` reconciles them.**

This exists because the app once drifted into re-rolling exercises weekly (incoherent, un-trackable)
while passing every structural gate — because nothing tested *doctrine*, only *legality*. That can no
longer happen: a change that violates the ACTIVE invariants below cannot ship.

| **D22** | The weight a user enters at onboarding ("what can you lift for 8–10 reps?") is a **submaximal rep-max, and must be converted through D12's `calcRM` before it prescribes anything** — it is never used as a working load directly. Onboarding has collected this number since EPIC-9 Step A, persisted it to `users.onboarding_estimates` and restored it on re-login, and consumed it in exactly ONE place: as the raw week-1 working weight. That is an 8–10RM being prescribed for a 12- or 15-rep week — a real over-prescription, not a rounding quibble (a user entering 225 was told to do 12 reps at the weight they can move 9 times). **Second-order effect, which is the bigger one:** because nothing ever became a 1RM, `getWeekTarget` returned `source:'none'` for every new user, so the whole %1RM engine (D11) sat idle and `getRecommendation` fell through to its flat `phase.incComp`/`incAcc` pound-step branch — the hardcoded 2.5/5/10 lb increments. One unconverted number was keeping the app off its own load model. **Conversion, and the choice inside it, stated not buried:** the card names a RANGE and stores no rep count, so a rep number must be chosen; we take the **bottom** (8). `calcRM` is monotonic increasing in reps (D12), so 8 yields the LOWEST 1RM the user's own answer supports — it under-estimates, and an under-estimate under-prescribes. ## The rule for every Epic / Bug / QA entry
Every program-touching change must (a) name the governing Notion doc above, (b) state how it conforms to
the relevant D-invariant(s), and (c) pass `npm run verify` (which now includes the doctrine gate). A change
that re-rolls lifts weekly, drops a required deload/superset, or invents a non-canonical goal is **wrong by
definition** — not a judgment call.
